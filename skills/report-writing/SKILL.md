# Report Writing（专业报告写作）

主流智能体（Claude / ChatGPT / Gemini）的通用能力：把零散信息组织成结构化、可信、可用的报告。

## 工作流

### 1. 定目标与读者
- 谁看？决策者要结论，执行者要步骤，汇报要看重点。
- 确定篇幅与形式（一页简报 / 详细报告 / 表格 / 汇报稿）。

### 2. 结论先行（金字塔结构）
- **开头给结论**，再给支撑，最后给建议。别让读者翻到底才知道你想说啥。
- 每段开头一句主题句，细节随后。

### 3. 数据与证据支撑
- 关键论断必须有数据/来源，标注出处。
- 不确定的标注"待核实"，不编造。

### 4. 结构化呈现
- 用标题层级、列表、表格组织；长文给目录。
- 写完自查：删掉废话，每句话是否有存在价值。

### 5. 审校
- 通读一遍改错别字、逻辑断点、重复。
- 用 `review_work` 做第二遍核对。

## 规范
- **用户要什么给什么**：要一页别给十页，要详细别省重点。
- **不做废话填充**：宁短勿水。
- **标题党禁止**：报告标题要如实反映内容。
