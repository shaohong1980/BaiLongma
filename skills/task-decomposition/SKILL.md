# Task Decomposition（复杂任务拆解）

主流智能体（AutoGPT / Devin / Manus）的核心能力：**把模糊的大目标变成可执行、可验收的小步骤**。

## 工作流

### 1. 澄清目标
- 最终"做成什么样"才算完成？用一句话说清可验收的结果。
- 收集约束：时间、资源、依赖、禁止项。

### 2. 逆向拆解（从终点倒推）
- 从最终结果倒推：要得到 X，必须先有 Y；要 Y，先做 Z。
- 每步做到"能独立验收"的粒度（这一步做完，我能判断对不对）。

### 3. 排序与依赖
- 标出先后依赖：哪些必须串行，哪些可以并行。
- 识别风险步骤，提前安排验证点。

### 4. 用 set_task 落地
- 调 `set_task(description, steps)` 把计划固化，系统会跟踪进度。
- 每完成一步调 `update_task_step` 更新状态。

### 5. 执行与调整
- 按步骤推进，卡住时回到"这步的目标是什么"换路径。
- 计划允许调整：需求变了就更新计划，别硬撑。

## 规范
- **小步可验**：步骤要小到"做完能立刻判断对不对"，别把整个项目当一个步骤。
- **先计划后动手**：复杂任务先给计划让用户确认，再开始执行。
- **完成即验收**：每步收尾做验证（读回产物/跑一下），别凭感觉说"做好了"。
