# File Management（文件整理）

主流智能体的实用能力：**安全、批量、可回滚地整理文件**。

## 工作流

### 1. 先摸清现状
- `list_dir` / `read_file` 查看目录结构、文件类型、数量。
- 先跟用户确认整理规则（按什么分类？命名规则？），不擅自定规则。

### 2. 规划并预览
- 列出"将做什么"：哪些文件移到哪、改成什么名、删除什么。
- 让用户确认后再动手，避免误伤。

### 3. 执行（可回滚优先）
- 用 `exec_command` 批量操作；**先试运行（dry-run）**，确认无误再真执行。
- 移动/重命名用"先复制到临时区再删源"，或保留原始结构可逆。

### 4. 清理与去重
- 删文件前列出清单，确认无引用/无价值再删。
- 大文件、重复文件先报告，不擅自删。

### 5. 整理后汇报
- 说明做了什么、移动到哪、删了什么、释放了多少空间。

## 规范
- **先问规则再动手**：不知道用户怎么分类就别自作主张。
- **可逆优先**：能复制/移动到备份区就别直接删。
- **干跑确认**：批量操作前给预览，用户点头再执行。
- **保留证据**：报告列出"源 → 目标"映射，方便复查。
