# Data Analysis（数据分析）

主流智能体（ChatGPT Code Interpreter / Gemini）的核心能力：**拿到数据 → 清洗 → 统计 → 洞察 → 可视化**。

## 工作流

### 1. 先理解数据
- `read_file` 读取数据文件，先看表头/字段/前几行，别急着算。
- 确认：多少行、什么字段、有无缺失/脏数据。

### 2. 清洗
- 去掉/标注缺失值、统一格式（日期、单位）、去重。
- 用 `exec_command` + node/python 处理，别手动数。

### 3. 统计与洞察
- 核心指标：总量、均值、极值、分布、环比/同比、占比。
- **回答用户真正关心的**，不是罗列所有数字。

### 4. 可视化（可选）
- 用 `generate_image` 或输出 Markdown 表格 / Mermaid 图表。
- 趋势用折线、占比用饼图、分布用直方图——选对图比画得花哨重要。

### 5. 结论
- 用 1-2 句话总结数据说明了什么，附关键数字。

## 规范
- **可复现**：说明处理过程（清洗了什么、怎么算的），让用户能复核。
- **不编数字**：所有数字必须来自实际数据，宁缺毋滥。
- **标注局限**：样本小、口径不清时要说明，别把数据当真相夸。
