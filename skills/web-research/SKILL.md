# Web Research（系统化网络调研）

主流智能体（Claude / ChatGPT / Copilot）的核心能力之一：把"打开几个网页"升级为"结构化调研 → 交叉验证 → 得出结论"。

## 工作流

### 1. 明确问题与产出
- 先确认：用户要什么结论？什么粒度（一句话 / 对比表 / 详细报告）？
- 确定 2-3 个搜索关键词维度，避免单关键词盲搜。

### 2. 多路搜索
- 用 `web_search` 覆盖不同关键词/站点，收集 3-5 个来源。
- 对中文问题，优先权威源（官方文档、官网、gov、edu）；对技术问题，优先官方文档 + GitHub。

### 3. 抓取原文
- 用 `fetch_url` 抓取命中页面的正文，**不要只信搜索摘要**（摘要常截断/误导）。
- 多个来源互相矛盾时，全部列出，标注可靠度。

### 4. 综合结论
- 按用户要求的粒度输出：结论放最前，证据按可靠度排序，最后给"不确定性"。
- 给出处链接，方便用户回溯。

## 规范
- **不编造来源**：没抓到原文的内容，标注"未验证"或"来自搜索摘要"。
- **不堆砌**：用户要"一句话结论"就别给三页报告；要对比表就给表格。
- **时效性**：价格、版本、政策类信息要说明查询时间。
