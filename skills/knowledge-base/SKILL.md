# Knowledge Base（个人知识库）

主流智能体的长尾能力：把零散信息**沉淀成可检索、可复用的知识**，而不是聊过就忘。

## 工作流

### 1. 识别值得沉淀的内容
- 用户说"这个很重要/以后要用/帮我记住"→ 值得。
- 操作类：步骤、命令、配置 → 值得。
- 结论类：调研结论、决策理由 → 值得。
- 一次性闲聊 → 不值得，别过度记录。

### 2. 用合适的方式沉淀
- **短期/待办**：`manage_todo`（工作台待办）。
- **长期目标**：`set_goal`。
- **事实/关系**：`upsert_memory`（结构化记忆）。
- **完整文档**：写到 `sandbox/notes/` 或 `skills/` 成文。

### 3. 组织成可检索结构
- 给标题、标签、关键词，方便 `search_memory` / `recall_memory` 命中。
- 相关知识点建立联系（谁相关、谁依赖谁）。

### 4. 定期复盘
- 用 `weekly_review` 每周总结：这周学到什么、踩了什么坑、下周做什么。
- 复盘能催生新的记忆和技能。

### 5. 技能化
- 反复用到的工作流，用 `learn_skill` 沉淀成 SKILL.md，下次直接套用。

## 规范
- **不过度记录**：用户没要求就别把每句话都记下来。
- **真实不编造**：记忆内容要忠于实际，不添油加醋。
- **可检索**：每条记忆都要有明确的检索线索（关键词/标签）。
