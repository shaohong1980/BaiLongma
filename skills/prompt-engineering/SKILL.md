# 提示词工程

## 好提示词五要素
1. **角色**：你是谁、什么立场（"你是资深产品经理"）
2. **任务**：一句话说清要做什么，动词明确
3. **约束**：边界/禁止项（"不超过200字""不要编造"）
4. **示例**：给 1-2 个输入→输出示例，尤其对格式要求
5. **输出格式**：结构（JSON/Markdown/表格）、字段、语气

## 模板
```
# 角色
你是{角色}。

# 任务
请{具体任务}。

# 要求
- {约束1}
- {约束2}

# 输出格式
{期望的结构}，例如：
{示例}
```

## 常见技巧
- **少即是多**：指令精简，别堆砌模糊要求
- **给判断标准**：说清"什么算好"，别只说"要高质量"
- **拆步**：复杂任务让模型分步（"先…再…最后…"）
- **防幻觉**：加"不确定就说不确定""只依据给定材料"
- **迭代**：输出不理想 → 改约束/示例 → 重测，别重写整个 prompt
- **测边界**：空输入、极端输入、恶意输入的表现

## 规范
- **先问用途**：给谁用、跑在什么模型、要什么输出，再写
- **给可测版本**：写完给一个输入让用户试，验证效果
- **标注假设**：模型能力（多模态？工具调用？）影响写法，说明假设
